# **java-racingcar-precourse**

## **🚗 자동차 경주**

---

### **🔷 기능 요구사항 정리**

| **구분**    | **기능명**           | **세부 설명**                                                                                                |
|-----------|-------------------|----------------------------------------------------------------------------------------------------------|
| **입력**    | **자동차 이름 입력**     | 사용자로부터 `“경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)”` 메시지와 함께 n개의 자동차 이름를 입력받는다.                              |
|           | **시도할 횟수 입력**     | 사용자로부터 `“시도할 횟수는 몇 회인가요?”` 메시지와 함께 시도활 횟수를 입력받는다.                                                        |
| **입력 파싱** | **자동차 목록 구성**     | 입력 문자열을 쉼표(,)로 분리하고 각 항목의 앞뒤 공백을 제거 후 저장한다. 입력 순서를 유지한다.                                                 |
|           | **라운드 수 구성**      | 입력 문자열을 앞뒤 공백 제거 후, 정수로 변환 하여 저장한다. 이때 숫자 형식이 아닌 경우 잘못된 입력으로 처리한다.                                       |
| **입력 검증** | **자동차 수 검증**      | 경주할 자동차 수가 0개 혹은 1개인 경우, 잘못된 입력으로 처리한다.                                                                  |
|           | **자동차 이름 유효성 검증** | 자동차 이름이 공백이거나, 5자 초과(공백포함)인 경우 잘못된 입력으로 처리한다.                                                            |
|           | **자동차 이름 중복 검증**  | 자동차 이름 중 중복된 이름이 있는 경우 잘못된 입력으로 처리한다.                                                                    |
|           | **시도할 횟수 검증**     | 시도활 횟수에 0이 입력된 경우 잘못된 입력으로 처리한다.                                                                         |
| **게임**    | **자동차 이동 결정**     | `Randoms.pickNumberInRange(0, 9)`로 난수를 생성하고, 4 이상이면 해당 자동차의 거리를 1 증가시킨다(그 외 변화 없음). 각 자동차·라운드별로 독립 수행한다. |
|           | **라운드 진행**        | 입력받은 시도횟수만큼 라운드를 반복 수행한다. 각 라운드마다 모든 자동차에 대해 자동차 이동 결정을 1회씩 수행한다.                                        |
| **결과**    | **최종 우승자 선정**     | 최대 이동 거리를 구해 해당 거리의 자동차들을 우승자로 선정한다.                                                                     |
| **출력**    | **실행 결과 헤더 출력**   | 게임 시작 전 `“실행 결과”` 메시지를 한 줄로 출력한다.                                                                        |
|           | **차수별 진행 상황 출력**  | 각 라운드 종료 직후, 입력 순서 그대로 `자동차이름 : {-(이동한거리만큼)}`형식으로 모든 자동차 상태를 출력한다. 이동거리가 0이면 - 표시는 없다.                   |
|           | **최종 우승자 출력**     | 선정된 최종 우승자를 `최종 우승자 : 이름1, 이름2` 형식(공동 우승 시 쉼표+공백)으로 한다.                                                  |
| **예외 처리** | **잘못된 입력 처리**     | 잘못된 입력 시 `IllegalArgumentException`을 발생시키고 애플리케이션을 종료한다. `System.exit()`는 사용하지 않는다.                      |

> 위 표는 기능 구현 목록을 담습니다. 프리코스 진행 방식에서 제시된 “기능 요구사항에 기재되지 않은 내용은 스스로 판단하여 구현한다”에 해당하는 내용은 아래 이렇게 판단했습니다 에 기재했습니다.
>

### **🤔 이렇게 판단했습니다**

- **자동차 이름**으로 **공백(””)이 입력된 경우 잘못된 입력**으로 처리했습니다
    - 과제의 첫 문장이 **`“초간단 자동차 경주 게임을 구현한다”`**로 시작하기 때문에, 참여할 자동차가 없는 경우는 게임의 전제에 맞지 않다고 판단했습니다.
    - 따라서 자동차 이름이 비어 있거나 공백만 포함된 경우 잘못된 입력으로 처리했습니다.
- **자동차 이름이 1개만 입력된 경우 잘못된 입력**으로 처리했습니다
    - 과제에서 **`“주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.”`** 에서, n대는 복수 개를 전제한 표현으로 생각했습니다.
    - 또한 참가자가 1명인 자동차 경주 게임은 더이상 비교 대상이 없으므로 우승 개념도 무의미해지기에 잘못된 입력으로 처리했습니다.
- **시도할 횟수**로 **0이 들어온 경우 잘못된 입력**으로 처리했습니다
    - 시도 횟수가 0이면 게임이 한 번도 진행되지 않으므로, 자동차 경주의 의미가 사라지므로 이 역시 잘못된 입력으로 간주했습니다.
- 자동차 **이름의 앞뒤 공백은 제거**하고, **이름 내부의 공백(띄어쓰기)은 그대로 유지**하도록 처리했습니다.
    - 이름 안의 공백은 허용하되, 양옆의 공백은 제거하여 **사용자 편의를 높이고 다양한 이름 조합을 수용**할 수 있도록 했습니다.
    - 즉, `pobi,woni,jun`과 `pobi, woni, jun`은 동일하게 올바른 입력으로 처리되며, 내부적으로 `pobi,woni,jun`으로 인식됩니다.
    - 반면 `pobi`, `po bi`, `pob i`는 서로 다른 자동차 이름으로 인식됩니다.
